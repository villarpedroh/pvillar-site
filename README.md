# pvillar.com

Personal design portfolio of Pedro Villar, served by GitHub Pages at https://www.pvillar.com.

Originally built in Webflow; this is the static copy of the published site.

- `index.html`, `about/`, `explorations/` — pages
- `assets/images/` — all images (with Webflow's responsive `-p-500/800/1080…` sizes)
- `assets/css`, `assets/js`, `assets/files` — styles, scripts, résumé PDF
